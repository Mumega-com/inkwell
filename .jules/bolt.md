## 2024-06-02 - Cache Intl.NumberFormat for Rendering Performance
**Learning:** Instantiating `new Intl.NumberFormat()` dynamically inside React component render cycles (such as in `KPICard`, `DataTable`, and various dashboard plugins) introduces unnecessary CPU overhead and garbage collection. This is particularly noticeable in lists or frequently re-rendered chart components.
**Action:** Centralized all `Intl.NumberFormat` usage into a caching utility at `src/lib/formatters.ts`. Always use `getCurrencyFormatter`, `getCompactFormatter`, or `getNumberFormatter` instead of direct `new Intl.NumberFormat(...)` instantiation to ensure high performance during renders. Also ensure that `maximumFractionDigits` is not hardcoded to 0 by default to prevent `RangeError` conflicts with caller overrides.
