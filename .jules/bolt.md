## 2024-06-01 - [Centralized Intl Formatter Caching]
**Learning:** [Repeatedly instantiating `Intl.NumberFormat` inside React render cycles (e.g., in DataTable loops or re-rendering KPICards) is a known performance bottleneck due to the CPU overhead of initializing the localization engine. While not visible in a single card, it adds up quickly in large tables or dashboards.]
**Action:** [Created a centralized module `src/lib/formatters.ts` that caches these instances by locale, currency, and options using a Map. Updated all React components in `src/components` and `plugins/` to use these cached formatters instead of inline instantiations. Remember to construct relative import paths carefully when referencing `src/lib` from deep inside the `plugins/` directory (e.g., `../../../src/lib/formatters`).]
