## 2024-06-24 - Centralized Intl Object Caching for Performance
**Learning:** Instantiating `Intl.NumberFormat` frequently within React component render cycles or loops incurs high CPU overhead and triggers aggressive garbage collection. This is a common performance pitfall in data-heavy views (e.g. dashboards, analytics tables).
**Action:** Created `src/lib/formatters.ts` to implement a caching strategy using a Map to store and reuse `Intl.NumberFormat` instances based on locale and options hash. This avoids repeated instantiation across the application. When wrapping `Intl.NumberFormat`, it's critical to avoid setting restrictive default options like `maximumFractionDigits: 0` that can conflict with caller overrides, as this throws a `RangeError: maximumFractionDigits value is out of range`.
