**Learning:** Instantiating `Intl.NumberFormat` frequently within React component render cycles (e.g., in `.map()` loops or `render` functions) is a known performance bottleneck in JS. However, the `formatters.ts` file doesn't actually exist in the current codebase state. The action is to recreate `src/lib/formatters.ts` and refactor the components to use it.
**Action:** Re-create `src/lib/formatters.ts` with caching logic to avoid repeated instantiations of `Intl.NumberFormat`, and update all React components instantiating `Intl.NumberFormat` inline to use these cached formatters.
