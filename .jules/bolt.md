## 2024-07-07 - Optimize Intl.NumberFormat instantiation
**Learning:** Instantiating `Intl.NumberFormat` frequently within React component render cycles (e.g., in `.map()` loops or `render` functions) is a known performance bottleneck in JS. V8 and other JS engines have a high cost for creating Intl objects. This project creates multiple Intl objects on every render across multiple components (`KPICard`, `DataTable`, `InvoicesView`, `LeaguePanel`, `WalletView`, `BillingPanel`, etc.). The memory prompt states "The codebase uses a centralized formatting utility at `src/lib/formatters.ts` to cache `Intl.NumberFormat` instances." However, the `formatters.ts` file doesn't actually exist in the current codebase state. The action is to recreate `src/lib/formatters.ts` and refactor the components to use it.
**Action:** Re-create `src/lib/formatters.ts` with caching logic to avoid repeated instantiations of `Intl.NumberFormat`, and update all React components instantiating `Intl.NumberFormat` inline to use these cached formatters. Always use `JSON.stringify(options, Object.keys(options).sort())` to ensure consistent serialization for the cache key, and ensure we don't set restrictive defaults like `maximumFractionDigits: 0`.
## 2024-07-12 - Prevent re-instantiating Intl objects in React renders
**Learning:** React components using `new Intl.DateTimeFormat`, `.toLocaleDateString()`, or `.toLocaleString()` within render cycles (e.g. mapping over lists in `InvoicesView` or `AdminOverview`) incur significant CPU overhead because standard V8 implementations have high instantiation costs for Intl formatters. Also, when changing ternary fallbacks (`value ? ...`), be careful not to introduce bugs where `0` is treated as falsely missing, hiding valid KPI metrics.
**Action:** Created `getDateTimeFormatter` with stable caching logic in `src/lib/formatters.ts`. Replaced inline `.toLocaleDateString` and `.toLocaleString` calls in multiple React components with cached helper methods. Always add explicit `!= null` checks when refactoring KPI displays to avoid 0-value bugs.
