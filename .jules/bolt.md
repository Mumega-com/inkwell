## 2024-06-18 - [Cache Intl.NumberFormat instead of creating inline in renders]
**Learning:** React components (like KPICard, DataTable) that create `new Intl.NumberFormat` instances dynamically on every render incur unnecessary CPU overhead, especially since this isn't memoized and these formatters are instantiated repeatedly across list items or re-renders. A centralized `src/lib/formatters.ts` does not exist but was requested by memory notes.
**Action:** Created `src/lib/formatters.ts` caching `Intl.NumberFormat` wrappers globally (not recreating instances on each call but using global cache maps for performance), then imported them in components instead of inline `new Intl.NumberFormat()`. Ensure no restrictive maximumFractionDigits defaults are set in wrappers to avoid RangeErrors.
